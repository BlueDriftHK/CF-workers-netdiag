    部署

    3 步拥有自己的诊断站

    不需要服务器、不需要构建、不需要 npm 依赖。绑定 KV 与管理密钥都是可选的。

    # 1) 克隆仓库（或点上方一键部署按钮）
git clone https://github.com/BlueDriftHK/CF-workers-netdiag.git
cd CF-workers-netdiag

# 2) 本地预览 / 部署上线
npx wrangler dev
npx wrangler deploy

# 可选：绑定 KV（站点监控状态 / 测速历史）
npx wrangler kv namespace create SPEED_HISTORY
# 可选：设置管理密钥（站点监控配置与手动巡检）
npx wrangler secret put MONITOR_ADMIN_KEY

# 3) 验证部署（/health 需要页面会话令牌，脚本探活请用 /node-ping）
curl https://your-worker.workers.dev/node-ping
# => {"ok":true,"version":"4.7.1","time":1730000000000}
    一键部署到 Cloudflare

    提示：`/health` 需要主页面签发的会话令牌（防爬虫），所以用 curl 直接访问会得到 403 —— 探活请用 `/node-ping`。
