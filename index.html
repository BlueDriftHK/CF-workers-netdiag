03 / DEPLOY

3 分钟部署

单文件 Worker，无需构建；绑定一个 KV 即可开启历史与统计。

01

克隆仓库

git clone github.com/BlueDriftHK/CF-workers-netdiag
02

安装 Wrangler

npm install -g wrangler
03

创建 KV（可选）

wrangler kv:namespace create "SPEED_HISTORY"
04

发布

wrangler deploy
所有绑定都是软依赖：未绑定 KV 时，历史与统计优雅降级，其余功能照常运行。也可在 Cloudflare Dashboard 直接粘贴脚本并绑定 KV。
04 / TECH & SECURITY

架构与安全

一个 Worker 脚本承载前端与后端，安全机制内建。

runtime Cloudflare Workers (V8, ES2020)
frontend 原生 JS SPA · Canvas · 零框架
storage KV — SPEED_HISTORY / CACHE_KV
limits per-isolate 限流 · 资源体积上限
i18n EN · 简体中文 · 繁體中文
  • CSP + 安全头

    随机 nonce 的脚本策略、nosniff、DENY、HSTS、Permissions-Policy。

  • 同源校验 + SSRF 防护

    敏感端点校验来源；URL 端点做协议/域名白名单与私网拦截。

  • 限流与资源上限

    通用 60/分钟 + CPU 端点 3/分钟；下载/上传/流式体积极限。

  • 转义分层

    HTML 与 JS 上下文分别转义，客户端渲染统一转义，防 XSS。
