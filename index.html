网络诊断
如极光般绚丽高效

NetSight Pro 是一款部署在 Cloudflare Workers 上的全功能网络诊断工具， 提供实时延迟监控、带宽测速、CPU 性能、WebSocket 延迟、TTFB 分析、WebRTC 泄漏检测等 20+ 项诊断能力。

部署到 Cloudflare 查看源码

⚡ 特性一览

一站式网络诊断，覆盖从链路质量到安全协议的全方位检测。

实时 RTT 监控

每 2 秒发送 HEAD 请求，绘制延迟趋势图，计算抖动、丢包率，自动评估连接质量。

带宽测速（下载/上传）

多档位下载和上传测试，计算平均速度，直观反映网络吞吐能力。

CPU 基准测试

执行密集型数学运算，评估 Worker 或客户端设备的计算性能。

WebSocket 延迟

建立双向 WebSocket 连接，进行 ping/pong 测距，反映实时双向通信延迟。

并发下载测试

模拟多路并发请求，检测网络在多连接场景下的吞吐表现。

流式传输吞吐量

流式读取大文件（最大 10MB），测试长连接下的稳定传输速率。

TTFB 分阶段分析

分解 DNS、TCP、TLS、等待、下载各阶段耗时，精确定位性能瓶颈。

安全与协议检测

显示 TLS 版本、加密套件、HTTP/2/3 支持、ECH 状态、JA3/JA4 指纹、机器人评分。

双栈 IP 与地理位置

同时获取 IPv4 和 IPv6，通过 ipapi.co 获取客户端真实地理位置及到边缘节点的距离。

IP 欺诈评分

集成 Scamalytics API，检测 IP 是否为代理/VPN/Tor/托管，并给出风险等级。

WebRTC 泄漏检测

检测本地和公网 IP 是否通过 WebRTC 泄露，保护隐私安全。

流媒体连通性

检测 Netflix、Disney+、YouTube、ChatGPT 等服务的可达性。

多节点对比

输入其他 Worker 节点 URL，并行测试延迟，生成直观对比表格。

测速历史与用量统计

存储最近测速记录，展示 API 端点调用统计（需 KV 支持）。

一键生成诊断报告

复制纯文本报告，包含所有关键指标，便于分享和存档。

多语言与主题

支持 English、简体中文、繁體中文，深色/浅色/跟随系统主题，自动适配。

🛠️ 技术栈

Cloudflare Workers JavaScript (ES2020) KV (可选) HTML5 + CSS3 毛玻璃设计 Canvas 图表 WebSocket 安全头 + CSP

🚀 快速部署

3 分钟即可拥有自己的网络诊断服务。

1

克隆仓库

git clone https://github.com/BlueDriftHK/CF-workers-netdiag.git

2

安装 Wrangler

npm install -g wrangler

3

配置 KV（可选）

wrangler kv:namespace create "SPEED_HISTORY"

4

发布

wrangler publish
