技术架构与安全

轻量、可缓存、默认安全。

架构要点

  • 边缘运行时 · 单文件 Worker，无构建步骤、无第三方依赖
  • 前端外置 · /app.js 与 /app.css 独立缓存，首页体积更小
  • 内存用量统计 · USAGE_BACKEND=memory，常规请求不产生 KV 读写
  • 按变化写 KV · 站点监控仅在状态翻转时写入，避免额度被刷爆
  • PWA · 可安装到桌面/主屏，Service Worker 提供离线外壳
  • 三语言 · 简体 / 繁體 / English 一键切换

安全加固

同源校验（fail-closed）已启用
SSRF 防护（DoH + 逐跳校验）已启用
独立限流桶（健康检查 / 大响应）已启用
严格 CSP + SRI已启用
上传体积限制（32 MB 流式）已启用
  • 出站探测优先 HTTPS（如 proxycheck.io），避免明文链路
  • 无 Origin 且无 Referer 的请求一律拒绝

3 步上云

无需服务器、无需构建，几分钟即可拥有自己的诊断站。

1

创建 Worker

Cloudflare Dashboard → Workers & Pages → 创建新的 Worker。

2

粘贴并部署

把 _workers.js 全文粘贴进编辑器，保存并部署。

3

访问验证

打开 Worker 域名，访问 /health 应返回 "version":"4.6.0"。

# 可选：绑定 KV 命名空间（站点监控 / 测速历史）
Name = SPEED_HISTORY
# 可选：设置管理密钥（打开站点监控配置）
MONITOR_ADMIN_KEY = your-secret

# 验证部署
curl https://your-worker.workers.dev/health
# => {"status":"ok","version":"4.6.0","storage":{"usageBackend":"memory"}}
