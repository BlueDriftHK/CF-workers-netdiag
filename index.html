From signal to decision

从一次采样，
到一个结论。

诊断不是把数字堆给用户。先采样，再分析，然后归因，最后给出可以执行的动作——这条链路在代码里是完整的。

采样

浏览器侧发起 RTT、DNS、吞吐和协议探测；能本地完成的，绝不额外经过 Worker。

分析

中位数、分位值、标准差、丢包率与稳定性评分，统一在同一套指标口径下计算。

归因

把“慢”拆成 DNS、TLS、首字节、下载、缓冲膨胀与协议限制，避免错误归因。

行动

给出可执行的建议：换 DNS、改有线、检查 Wi-Fi 干扰、观察证书到期或调整监控阈值。

Engineering

优雅的表象，
靠克制的基础设施。

单文件发布，模块化开发。构建脚本保证输出可复现，回归测试覆盖令牌、限流、监控与多语言，观测指标直接暴露为 Prometheus 文本。

Deploy

三步，拥有你自己的
边缘诊断站。

不需要服务器，不需要数据库。绑定 KV 与管理密钥都是可选项；不配置也能获得完整的浏览器侧诊断能力。

STEP 01

准备配置

复制 wrangler 模板，按需修改 SITE_CONFIG：站点名、默认语言、禁用工具与指标密钥。

STEP 02

写入密钥

设置 PAGE_TOKEN_SECRET 与 MONITOR_ADMIN_KEY，开启跨 isolate 令牌与监控管理。

STEP 03

部署上线

一条命令发布到 Cloudflare Workers，几分钟内获得属于你的诊断入口与监控能力。

$ npm run build && npx wrangler deploy

现在，把网络看透。

把它部署到你自己的域名，从第一次采样开始，建立属于你的网络基线。
